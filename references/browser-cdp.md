# 浏览器与 CDP 操作约定

## 选择现有能力

先查看当前 Agent 的技能目录、浏览器工具和本地接口，选择已经具备的浏览器能力。需要页面交互时优先使用可读取可见标签、角色和页面状态的工具；单纯能发 HTTP 请求，不代表具备完整账号设置能力。

普通浏览器和指纹浏览器都可使用。AdsPower / CDP 是可选适配方式，不是 Google 设置的前置条件。运行位置是操作者本机，不依赖业务服务器。

## 连接前

1. 从私密来源取得指定账号与浏览器环境的映射。公开示例只使用 `PRIVATE_PROFILE_REF`、`PRIVATE_CDP_ENDPOINT_REF` 等占位符。
2. 使用浏览器提供方已安装版本的文档或接口核对当前活动环境、启动参数及连接信息；不要套用历史环境编号或硬编码端口。
3. 已打开环境默认视为用户正在使用，只有用户明确指定接管才操作。新开环境只使用用户指定的配置，不改写共享代理、设备指纹或浏览器语言。
4. 如果本次有预期网络出口要求，在当前浏览器内核对，只在报告写“匹配/不匹配”；没有此项要求时跳过外部出口查询。
5. 在运行项目的 `.cache/<run-id>/` 建立受保护的资源清单，记录本次创建的页面、上下文、环境与进程。创建成功后立即纳入 `finally` 清理逻辑。

## 浏览器连接

- CDP 地址属于敏感的会话控制入口。放在私密配置引用中，保持回环访问；日志省略实际端口、WebSocket 标识和连接凭据。
- 连接既有浏览器后，先列出页面并读取账号身份；保留原生启动页、用户已有页面及其布局。
- 使用既有会话时复用对应上下文；隔离上下文通常没有原会话 Cookie，只用于用户明确要求的新登录验证。
- 如通过 CDP 创建隔离上下文，沿用环境语言配置，不另外传 `locale` 来改变原 `navigator.languages`。
- 避免为了设置密码而清空 Cookie、退出全部会话或重置环境；这些属于额外变更。

## 每次提交前的检查

按下面的顺序重新读取，而不是依赖旧快照：

1. 当前页面是否是预期 Google HTTPS 页面。核对解析后的 hostname，警惕相似拼写；账号管理常见域名为 `myaccount.google.com`、`accounts.google.com`，Gmail 为 `mail.google.com`。
2. 当前表单或账号菜单显示的完整邮箱是否等于指定账号。
3. 当前字段是否属于本次要求的项目，目标值引用是否仍然有效。
4. 输入后在本地读取字段并比较，输出只保留 `matches_expected: true/false`。
5. 保存后等待有界的页面反馈；重新读取可见状态，必要时刷新或重新进入该设置。

可以使用当前页面真实可见的文本、角色和标签定位元素。不要把某次会话的动态 DOM ID、坐标或账号 URL 直接固化为通用选择器。定位不唯一时重新检查页面。

常见中英日标签仅用于辅助识别，不作为唯一定位依据：

| 中文含义 | English | 日本語常见文本 |
|---|---|---|
| 恢复邮箱 | Recovery email | 再設定用のメールアドレス |
| 恢复电话 | Recovery phone | 再設定用の電話番号 |
| 两步验证 | 2-Step Verification | 2 段階認証 |
| 密码 | Password | パスワード |
| 通行密钥 | Passkeys | パスキー |

## 敏感输入与系统弹窗

普通浏览器工具可能记录输入参数、DOM 或截图。先核对工具的敏感输入能力；没有受保护输入通道时，由用户在页面填写密码、验证码或密钥，再由 Agent 读取非敏感的完成状态。

Authenticator 二维码/设置密钥、备用验证码、输入框里的密码、恢复邮箱完整地址都可能出现在页面快照中。默认不采集这类页面截图，不把 DOM、HAR、trace、storage state 或 Cookie 导出到公开目录。

Passkey 创建与使用通常会打开系统原生界面。DOM 只证明网页发起了请求；系统指纹、屏幕锁、硬件密钥或跨设备确认完成后，还要回到 Google 页面核验。不要使用虚拟 WebAuthn 认证器制造成功记录。

## 结束或中断

- 成功、失败或取消都按资源归属清理。只关闭本次创建且不再需要的临时页面和上下文。
- 如果用户需要接手验证码或系统弹窗，保留对应会话，并明确记录保留原因与后续清理条件。
- 用户原有的浏览器进程、环境、共享代理和页面保持原有状态。
- 断开 CDP 客户端前核对库的关闭语义，避免将“断开连接”误做成“退出整个浏览器”。
- 通过当前页面列表、活动环境或进程身份复核清理结果，而不是只记“已调用关闭”。
